# AST Analysis

## Mô tả
Dự án phân tích mã Python bằng AST. Task 1: thiết lập môi trường phát triển (Python, Git, VS Code, pytest).

## Yêu cầu
- Python 3.10+
- Git, VS Code

## Cài đặt (Windows PowerShell)
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Chạy chương trình
```powershell
py src\hello.py
```

## Chạy test
```powershell
pytest -v
```

## Cấu trúc thư mục
```
ast-analysis/
├── src/hello.py
├── tests/test_smoke.py
├── requirements.txt
```
